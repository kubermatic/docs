## KDP 1.2

- **MCP gateway.** KDP can expose its MCP server as a public HTTPS endpoint, so AI assistants can
  connect without a kubeconfig. See
  [MCP Gateway]({{< ref "/developer-platform/v1.2/guides/platform-administration/mcp-gateway" >}}).
- **AI Agent removed.** The KDP AI Agent chart is no longer part of the release. To use AI
  assistants with KDP, see
  [AI Tooling]({{< ref "/developer-platform/v1.2/guides/platform-users/ai-tooling" >}}).

To upgrade from 1.1, see
[Upgrading to 1.2]({{< ref "/developer-platform/v1.2/guides/platform-administration/upgrade" >}}).
